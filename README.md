🐍 Snake Water Gun Game

A simple Snake-Water-Gun game built using Python where the player competes against the computer. The computer randomly selects Snake, Water, or Gun, and the program determines the winner based on the game rules.

📌 Project Overview

This project is a beginner-friendly Python implementation designed to practice fundamental programming concepts such as:

Functions
Conditional statements
Dictionaries
Sets
User input
Random number generation
Input validation
Basic program structure
🎮 Game Rules
Choice	Beats
🐍 Snake	💧 Water
💧 Water	🔫 Gun
🔫 Gun	🐍 Snake

If both the player and computer select the same option, the game ends in a draw.
